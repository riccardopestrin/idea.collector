Idea Collector

Design language

Brutalist, industrial, minimal. Visual reference for anyone touching the UI: every value below mirrors globals.css, tokens.ts and icons.tsx.

Principles

  • Four colors, no gradients. No gradients, no blurred shadows, no decorative opacity. Transparency is only used for secondary text (ink at 50–70%).
  • Sharp corners. No border-radius, ever. Solid 1px ink borders separate everything.
  • Hard relief. The only shadow allowed is a solid offset: 4px for cards on hover, 8px for modals and dialogs.
  • No emoji, no decorative characters. Icons are inline SVGs with a 2px stroke and square caps.
  • The hover rule. Transparent turns ink; ink turns paprika; text links turn paprika. The paprika (destructive) button does the opposite and turns ink. 150ms transition, disabled under prefers-reduced-motion.
  • Labels in uppercase mono. Section titles, meta, buttons and tags use uppercase, letter-spaced IBM Plex Mono. Running text uses IBM Plex Sans.
  • Overlays, not breadcrumbs. Proposal detail, new proposal and profile open in a window above the current page; closing it leaves you where you were.

Forms

Uppercase mono label above the control, control in Plex Sans with a 1px ink border on paper (controlClass). Errors in paprika below the field, with role="alert". Visible 2px paprika focus ring.

Profilo

Column: 1px border, mono header with count, no fill. Card: 1px border, lifts 2px with a 4px hard shadow on hover (liftClass); the X in the top-right corner is set into the border. Modals and dialogs: 1px border, 8px hard shadow, ink backdrop at 60%, X in the corner.

Icons

20×20 grid, 2px stroke, stroke-linecap: square, stroke-linejoin: miter, currentColor, aria-hidden: meaning comes from the surrounding text or the container's aria-label. New icons go in src/components/icons.tsx in the same style.

Scrollbar

Scroll inside this box, horizontally or vertically.

8px, rectangular ink thumb on a paper track, paprika on hover. Invisible at rest and shown only while scrolling: ScrollbarReveal marks the element with data-scrolling and clears it after 800ms. Firefox uses its own thin scrollbar with the same colors.

Layout and spacing

  • Header with an ink bottom border: wordmark on the left; inside a project, back arrow, mono project name and nav; profile and "Esci" on the right. Wraps below 700px.
  • Page padding 24px; page title followed by the primary button, right-aligned on the same row.
  • Board: 320px columns (BOARD_COLUMN_WIDTH) with a 16px gap (BOARD_GAP), horizontal scroll inside the container, never on the page.
  • Single-column forms, max width 32rem, 20px gap between fields. Detail panel in two columns above 1024px: content and comments separated by a vertical border.
  • Spacing through flex and grid gap, not per-element margins. No inline values: shared dimensions live in tokens.ts.
